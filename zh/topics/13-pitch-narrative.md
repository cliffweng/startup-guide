# Pitch 敘事結構
{: .no_toc }

*約 8 分鐘*

## 為什麼重要

你會解釋這家公司幾百次：對用戶、招募、教授、天使。Pitch 不是 deck，也不是表演。它是一小段句子，讓陌生人懂你在做什麼、為什麼現在重要、以及你要他們做什麼。如果兩分鐘講不出來，你自己也還沒懂——沒有投影片設計藏得住。

Pitch 的內容是前面幾頁的工作。如果句子感覺空，修的通常是更多用戶對話，不是更多投影片。

## 核心概念

- **用非創辦人會重複的話，從你做什麼開始。** 「我們幫[具體的人][做那件工作]，不用[痛苦的替代做法]。」不是一個類別（「我們是 platform」），也不是一項技術（「我們是 AI-powered solution」）。如果你父母聽不懂第一句，它還沒好。這跟 [wedge](../02-idea-wedge/) 是同一句。
- **然後是你見過那個人的證明。** 真實對話或真實使用事件裡的一個具體細節，勝過一段市場規模。 「三個社團財務長上個月用我們的表對完會費」是 pitch。「學生組織市場有 $4B」除非有人問規模，否則是閃躲。
- **Why you、why now——各一句。** 為什麼你能接觸到他們。什麼變了，讓替代做法更糟或產品新近變可能。兩邊都必須可核對。「我們很有熱情」不是 why you。
- **你做了什麼，依*這個*聽者覺得厲害的順序。** 用戶在乎明天對他們有什麼改變。招募在乎他們會做什麼、以及創辦人講不講真話。投資人在乎你開始之後做了什麼：成長、使用、營收、速度。用最強的真事實開頭。不要用願景開頭然後希望他們保持清醒。
- **Ask 要具體。** 用戶：星期四試。招募：下週一次工作 session。投資人：下一場會，或一個你能大聲講出金額的支票。「想聽聽你的想法」浪費他們唯一準備好做事的那一刻。
- **兩個長度就夠。** 三十秒（這是什麼、給誰）和兩分鐘（加上洞察、traction、ask）。十分鐘獨白創造講出他們不喜歡的東西的機會。讓他們把更多拉出來。投影片如果要用，跟這個順序——它們不是敘事。
- **清楚就是全部手藝。** 刪掉行話、縮寫、以及要求聽者認識 X 的「X for Y」類比。對團隊以外的人大聲讀。他們皺眉的地方，重寫。他們說「喔，像 ___」的地方，偷他們的話。

## 接下來做什麼

- [ ] 在紙上寫 30 秒版。最多三句：這是什麼、給誰以及為什麼痛、你要什麼。
- [ ] 把兩分鐘版寫成六拍：這是什麼、痛苦的故事、why now、你做了什麼、why you、ask。幫自己計時。超過兩分鐘就砍一拍，不要講更快。
- [ ] 這週對一個不是 cofounder 的人講。請他們重複你在做什麼。改到他們的版本對得上你的。
- [ ] 口頭版能用之後，才做一頁 leave-behind：同樣那些拍、幾乎沒有形容詞。Deck 是可選的；糊的 deck 比沒有 deck 更糟。
- [ ] 從[指標](../07-metrics-that-matter/)試算表每週更新一行「證明」，讓 traction 那句永遠不會漂進小說。
- [ ] 練習 ask 直到它不再道歉。「我們在探索」不是 ask。

## 心智模型

```
  30 秒
  -----------
  1. 我們幫[誰]做[工作]。
  2. 今天他們[痛苦的替代做法]。
  3. Ask: [具體的下一步]。

  2 分鐘依這個順序加上
  ------------------------------
  4. 一個真故事或數字。
  5. Why now（一個變化，不是心情）。
  6. 為什麼這個團隊接觸得到這些用戶。
  然後停止說話。

  聽者                用這個開頭
  ---------           ---------
  用戶                他們這週的工作
  招募                工作和關於 runway 的真話
  投資人              你已經做了什麼
```

同一家公司，同一條脊椎。不同的第一個證明。從來不是不同的小說。

## 常見失敗模式

- **用市場或 model 開場。** 你大概有一句話的時間，他們就決定要不要聽。用在你做的那件工作上。
- **一段沒有事實的願景。** 沒有「上週發生了這個」的野心是課堂專案。放進那個小的真數字。
- **把 ask 埋起來，或有五個 ask。** 選一個動作。你可以同時想要介紹*和* pilot *和*招募；你向這個人要的是他們做得到的那一個。
- **背形容詞。** 「Revolutionary, seamless, AI-native」是聽者學會你沒有一句話的方式。具體才是風格。

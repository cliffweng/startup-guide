# 股權與 cofounder 協議
{: .no_toc }

*約 9 分鐘*

## 為什麼重要

股權是你怎麼拆還沒兌現的工作的上檔。怎麼拆、以及圍著它的 vesting，決定 cofounder 能不能在第四個月帶走半家公司，以及留下來的人還願不願意幹。多數早期爆炸不是因為點子。是因為從沒寫下來的不清楚期待。先把概念搞對，再讓律師寫協議。不要凌晨一點下載一份 template 自己「弄公平」。

不是法律、稅務或感情建議。只有概念。跟律師落紙——見[Incorporation](../09-incorporation-high-level/)。

## 核心概念

- **往前看，不要往後看。** 相關問題是「接下來幾年誰會做這個工作」，不是「九月是誰想到這個點子」。點子是便宜的那一半。執行才是公司。大幅獎勵「有點子」的人、輕獎會把它做出來的人，這種拆法傾向會破。
- **一起開始的全職 cofounder 通常接近均分。** 兩個人都放棄替代選項、都在做這份工作，50/50 或 60/40 是正常的。90/10 的「cofounder」是帶著混亂職稱的早期員工。如果你沒辦法看著他們的眼睛解釋那個落差，落差就是錯的。
- **Vesting 就是那份協議。** 股票或 options 隨時間賺到，常見是四年、一年 cliff：一年內離開，你幾乎或完全不留；之後每月增加一份。Vesting 讓分手還活得下去。「我們互相信任」不是替代品。單一創辦人把自己的股份 vest 也很正常——未來投資人預期如此。
- **把股權在代理的那些期待寫下來。** 誰全職、從何時起。誰負責產品、誰負責通路。什麼叫「離開」。未 vest 的股份怎麼辦。意見不合時決定怎麼做（打破平手勝過僵局）。這些屬於 cofounder 對話*以及*律師認得出來的文件，不只屬於氣氛。
- **Advisor 和早期幫忙的人拿一點，帶 vesting，換具體幫忙。** 個位數的十分之幾個百分點，不是「介紹就 10%」。如果有人要 cofounder 股權，他們就該做 cofounder 的工作。
- **Option pool 是給不是創辦人的人。** 那是你怎麼招募。創造它會 dilute 某人。在投資人「請你 refresh pool」講得像免費之前，先知道這件事。招募數字住在[招募](../11-hiring-first/)；pool 是貨幣。
- **如果你是加入，你在這件事的另一邊。** 問：百分比、fully diluted；vesting 長度和 cliff；vesting 起始日；被解雇 vs 自己離職會怎樣；有沒有 early exercise。你不是在刁難。你是在讀創辦人早該懂的那份協議。現金薪資和 runway 屬於同一場對話——一家只剩六週現金的公司的股權是樂透。見[Runway](../08-runway-unit-economics/)。

## 接下來做什麼

- [ ] 這週、在更多程式碼落地之前，把尷尬的對話談完：怎麼拆、全職日期、角色、以及如果其中一個拿到 return offer 離開會怎樣。
- [ ] 同意創辦人股權要 vest。如果有人拒絕，把那當成關於這段夥伴關係的資訊，不是法律技術細節。
- [ ] 寫一頁白話摘要，記下你們同意的事。把那一頁交給律師，變成真正的股票文件。不要互簽 Google Doc 然後當成做完。
- [ ] 開始一份對得上文件的 cap table（即使是試算表）：創辦人、pool、其他任何人。有變就更新。記憶不是 cap table。
- [ ] 如果第三個人「有一點在參與」，這個月決定：cofounder、帶小額 grant 的 advisor、或免費幫忙的朋友。Limbo 是 cap table 腐爛的方式。
- [ ] 如果你是加入的那個人，先讀 offer、寫問題，再談那個數字。結構跟百分比一樣重要。

## 心智模型

```
  公司 = 100%
     |
     +-- 創辦人，約 4 年 vesting（約 1 年 cliff）
     +-- option pool，給未來招募（不是「額外」——它會 dilute）
     +-- 之後: 投資人

  公平的拆法回答:
     從今天起誰會做這個工作？
     一個人離開，公司還活不活得下去？

  文件:  律師等級的協議
  不是文件:  握手加一頁 Notion
```

信任是你們一起開始的理由。Vesting 是信任用完時公司還能繼續的理由。

## 常見失敗模式

- **因為感覺冷血而不做 vesting。** 同意的那天晚上感覺冷血，有人離開的那個月非常昂貴。趁你們還喜歡彼此時做。
- **股權均分、投入不均。** 一個人全職、一個人「無限期晚上和週末」的 50/50 不是均分。把拆法對準往前的投入，或等到兩個人真的都進來。
- **Cap table 上一個沉默的 cofounder。** 名字在文件上、Slack 安靜了一學期的人。現在談，趁修復還是一場對話。
- **在 Slack 承諾股權。** 「我給你 5%」沒有董事會批准、沒有 vesting、沒有證券建議，是你同時蒐集一個懷恨的朋友和法律問題的方式。帶他們走律師那條路，或不要承諾。

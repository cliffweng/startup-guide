# Incorporation，概念層
{: .no_toc }

*約 8 分鐘*

## 為什麼重要

公司是一個獨立的法律人格：能擁有產品、簽合約、開銀行帳戶、發行股權。在那存在之前，*你*以亂七八糟的方式擁有風險和 IP，投資人通常也不會打錢。你不需要變成律師。你需要知道美國 venture-backed 軟體新創實際在用的那一個模式、它何時開始重要、以及該交給律師什麼而不是自己發明。

這一頁不是法律建議、不是申辦指南、也不是美國以外實體的比較。如果你不是朝美國 venture 風格的公司在走，停在這裡，跟你實際營運所在地的律師談。各國 incorporation 是這份手冊明確的非目標。

## 核心概念

- **常見的美國 venture 模式是 Delaware C-corporation。** 投資人、option plan、和新創律師事務所都為它準備好了。那是協調事實，不是 Delaware 對每個學生專案、顧問業、或非美國團隊「最好」的道德主張。LLC 可以是你不打算募 venture 的小型現金生意的正確盒子。如果你可能向天使或基金募，不要即興一個結構——早點問新創律師，因為之後轉換是一個專案。
- **獨立就是獨立。** 公司應該擁有 IP、網域、銀行帳戶、和合約。創辦人把 IP 轉進去。把個人 Venmo、裝滿未轉讓程式碼的個人筆電、和「之後再補紙本」的握手混在一起，是小爭執變成公司募不到資的方式。
- **時機是「在別人的錢和認真的 IP 之前」，不是「demo day 那天早上」。** 你可以以個人身分跟用戶談。一旦有人在付真錢、cofounder 在寫你們打算一起擁有的程式碼、或投資人有興趣，實體和轉讓就需要存在。更早是文書。更晚是一團亂。
- **走標準路徑。** Clerky 這類新創設立服務、或每週都在做這件事的律師，存在是為了讓你拿到無聊、投資人熟悉的文件。章程裡的新奇不是功能。你不是在公司形式上耍聰明。
- **你該預期存在、但不需要背下來的紙：** certificate of incorporation、bylaws、founder stock purchase agreements、IP assignment、以及一份對得上那些文件的 cap table。律師或標準服務產出這些。你讀。你不要複製一份隨便的 gist。
- **股權文件有不可選的期限。** Vesting、以及律師告訴你的任何稅務選舉（在美國人們會提到 83(b)）是有時間壓力的。行動是：股票授予的那週問律師，不是第三個月才 Google。這份手冊不會帶你走申辦。
- **銀行帳戶、記帳、以及「不要混用」是營運下限。** 實體存在後開公司帳戶。公司成本從那裡付。每張收據都留。那就是[runway](../08-runway-unit-economics/)變複雜之前你需要的整套會計——不是 ERP。
- **如果你是加入而不是創辦，** 你不是在 incorporation。你是在確認*他們*做了：offer 來自一家公司、你寫的 IP 會轉給它、而且有人能告訴你股權文件的狀態。含糊的答案是放慢的理由。

## 接下來做什麼

- [ ] 決定哪一句是真的：「我們可能在美國募venture或發 options」或「這是小專案 / 非美國，我們需要當地建議。」不要騎牆。
- [ ] 如果是美國 venture 路徑，這個月約新創律師或標準設立服務。帶：創辦人名字、大致均分或不均（見[股權](../10-equity-cofounder/)）、誰當 officer、以及你要一個無聊的 Delaware C-corp。問他們在文件簽完之前你*不該*做什麼。
- [ ] 列出每一項必須搬進公司的資產：repo、網域、設計、名稱、公司成立前寫的任何程式碼。沒有東西停在「我個人 GitHub 上，相信我」。
- [ ] 實體存在後，開銀行帳戶，把[runway 追蹤](../08-runway-unit-economics/)指向它。
- [ ] 把要問律師的問題寫下來，不要在群聊裡解決：founder stock、vesting、IP、以及有沒有人已經在領薪。
- [ ] 不要從 blog 文章亂申辦表格，也不要從投資人的推文拿實體建議。一小時律師費，比一份募不到資的 cap table 小。

## 心智模型

```
  你們，作為人                 公司（一個獨立的盒子）
  ---------------                ----------------------------
  點子、勞動、名聲               擁有 IP、合約、現金
                                 對創辦人發行股票
                                 能招募和募資

  這個盒子的美國 venture 預設: Delaware C-corp
  （投資人預期的慣例——不是全球答案）

  你的工作:  選路徑、用標準文件、
             把 IP 轉進去、現金分開、
             問律師期限
  不是你的工作:  發明結構，或變成律師
```

無聊的公司形式是功能。新奇的東西應該是產品。

## 常見失敗模式

- **一學期的程式碼沒有轉讓。** 離開的人仍然擁有他們寫的東西。在時間壓力下、或吵完之後修，很慘。
- **「我們先當 LLC，募到再轉。」** 有時是對的，常常是一場意外的稅務和法律專案。在 cap table 上有朋友之前，跟律師決定。
- **混用的錢。** 個人開銷從公司出，或公司營收進個人帳戶，把帳和「獨立實體」的故事一起炸掉。
- **優化稅務 trivia 而不是跟用戶談。** 選實體找不到客戶。花一個下午在設立上，然後回到 wedge。
